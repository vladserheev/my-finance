# План реалізації

Після кожного кроку: `uv run bean-check main.beancount` без повідомлень, оновити `PROGRESS.md`, коміт українською.

1. **Каркас.** `main.beancount`: опції, відкриття рахунків (Assets, Income, Expenses за категоріями з PRD), рядок `include "transactions.beancount"`. Початковий залишок 4 500 зл на 31.07.2026.
2. **Правила.** `rules.csv` (шаблон, рахунок, фіксована): конкретніші шаблони вище (`Bolt Food` перед `Bolt`).
3. **Імпорт.** `import.py` читає `data/*.csv` у порядку банку, прибирає дублікати, пише `transactions.beancount`. Фіксовані витрати отримують тег `#fixed`.
4. **Звірка.** Підсумковий залишок з Beancount має збігтися з останнім Balance у виписці.
5. **Запити.** Збережені `query` у `main.beancount`: витрати за категоріями по місяцях; дохід, витрати, норма заощаджень; фіксовані vs керовані; операції в «Без категорії».
6. **Звіт.** `report.html` з трьома відповідями, позначкою «неповний місяць» для жовтня і рядками «Без категорії» та «Інші надходження».
7. **Fava.** Перевірка перегляду через `uv run fava -p 5050 main.beancount`.
