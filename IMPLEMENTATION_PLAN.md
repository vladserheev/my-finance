# План реалізації

Після кожного кроку: `uv run bean-check main.beancount` без повідомлень, оновлений `PROGRESS.md`, коміт українською.

## Крок 1. Каркас
- **Зробити:** `main.beancount` з опціями (валюта PLN), `open` для всіх рахунків, початковим залишком 4 500 зл на 2026-07-31 і `include "transactions.beancount"`.
- **Перевірити:** `uv run bean-check main.beancount` не видає повідомлень.

## Крок 2. Правила категорій
- **Зробити:** доповнити `rules.csv` правилами для Play, Rossmann, Decathlon. Конкретніші шаблони лишаються вище (`Bolt Food` перед `Bolt`).
- **Перевірити:** кожен рахунок із `rules.csv` відкритий у `main.beancount`; bean-check чистий.

## Крок 3. Імпорт
- **Зробити:** `import.py` читає `data/*.csv` у порядку банку, не рахує дублікати двічі, пише `transactions.beancount`; фіксовані отримують `#fixed`.
- **Перевірити:** `uv run python import.py`, потім bean-check; рахунок «Без-Категорії» порожній.

## Крок 4. Звірка із банком
- **Зробити:** порівняти залишок рахунку в Beancount з останнім Balance у виписці.
- **Перевірити:** суми збігаються до копійки.

## Крок 5. Запити
- **Зробити:** збережені `query` у `main.beancount`: витрати за категоріями по місяцях; дохід, витрати і норма заощаджень; фіксовані проти керованих; «Без категорії» та «Інші надходження».
- **Перевірити:** `uv run bean-query` дає числа, які сходяться з ручним підрахунком за серпень.

## Крок 6. Звіт
- **Зробити:** `report.html` з трьома відповідями і позначкою «неповний місяць» для жовтня.
- **Перевірити:** файл відкривається в браузері, суми збігаються із запитами.

## Крок 7. Fava
- **Зробити:** запуск `uv run fava -p 5050 main.beancount`.
- **Перевірити:** сторінка відкривається на `localhost:5050`, помилок у розділі Errors немає.
