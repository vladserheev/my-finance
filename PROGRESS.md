- Інтервʼю з Олею (5 питань), рішення зафіксовано в `PRD.md`.
- Створено `PRD.md`, `IMPLEMENTATION_PLAN.md` (кроки зі «Зробити» і «Перевірити»), `PROGRESS.md`.
- У `CLAUDE.md` дописано розділ «Проєкт».
- Крок 1: каркас `main.beancount` (рахунки, початковий залишок 4 500 зл, `include`). `bean-check` пройшов без повідомлень. Порожня заготовка `transactions.beancount` (поза git).
- Крок 2: у `rules.csv` додано Play (фіксована), Rossmann, Decathlon. Усі рахунки з правил відкриті в `main.beancount`, `bean-check` чистий.
- Крок 3: `import.py` (`uv run python import.py`) створює `transactions.beancount`: 142 операції, жодної в «Без-Категорії», 17 з тегом `#fixed`. `bean-check` чистий.
- Крок 4: `import.py` додає balance-твердження з колонки Balance: 1 вересня (8 596,30), 1 жовтня (12 305,39) і 16 жовтня (17 127,34). `bean-check` пройшов без повідомлень, облік збігається з банком. У «Без-Категорії» операцій немає.

- Крок 5: у `main.beancount` п'ять збережених запитів (`витрати-за-категоріями`, `дохід-і-витрати`, `фіксовані-проти-керованих`, `без-категорії`, `інші-надходження`). Запуск: `uv run bean-query main.beancount ".run назва"`. Серпень збігається з CSV: витрати 5 703,70 зл (фіксовані 3 508,49 + керовані 2 195,21), дохід 9 800 зл. `bean-check` чистий.

- Крок 6: `report.py` (`uv run python report.py`) створює `report.html` з трьома відповідями. Жовтень позначено «неповний місяць». Суми збігаються із запитами; відкладене за серпень (4 096,30 зл) сходиться із залишком банку на 1 вересня. `report.html` не в git.

- Крок 7: Fava запускається командою `uv run fava -p 5050 main.beancount`, сторінка відкривається на `localhost:5050` (заголовок «Фінанси Олі»), список помилок порожній.

- Частина 2 (трекер для двох): штучні виписки в `demo-data/`, `import.py` читає обидва формати банків, рахунки Оля/Марко, `check.py` (одна команда з README) друкує контрольні цифри, всі чотири збігаються. `app.py`: Flask-сторінка з входом за паролем із змінних середовища, звітом за місяць і формою готівки (перевірено локально). `bean-check` чистий.
